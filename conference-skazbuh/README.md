# Конференция «Сказочная бухгалтерия»

III Форум главных бухгалтеров · компания «1+1» · 5 ноября 2026, Барнаул

> **Важно:** это дизайн **отдельного мероприятия** (конференции для главных

> конференции, живёт здесь, в этой папке, и не смешивается с корневыми

| Файл | Что это |

## Фирменный стиль конференции

Отдельная «сказочная» айдентика мероприятия: фиолетовый градиент, красный
акцент, фолк-мотивы (кокошник, счёты, звёзды). Отличается от основного
светлого стиля «1+1» (crimson + olive), описанного в `../docs/brandbook-1plus1.md`.
