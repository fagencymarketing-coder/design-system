# Шаблоны для PowerPoint

`1plus1-templates.pptx` — **рабочий файл заказчика** (13 слайдов 1080×1080: V1, V13, V2, V14, V3, V6, V8, V9, V11 и срочные U2, U3, U5, U6).
В нём её правки и удалённые слайды. Все дальнейшие изменения вносятся в этот файл (`tools/pptx/patch_user_file.py`),
а не пересобираются с нуля: пересборка `build.py` затрёт правки.

**Текст** во всех шаблонах — «рыба» (Здесь будет заголовок…). Заменяйте своим. Рубрика «Срочные новости» оставлена.
**Фото** (V6, V8, V9, V11) и **иконки-водяные знаки** (V5, V11, V12) — картинки-заглушки: выделить →
правая кнопка → «Изменить рисунок» (рамка и обрезка сохраняются). Фото, которые занимают весь макет (V1, V13), — фон.
Логотип — отдельная картинка. Малиновые черты — фигуры.

`icons-png/` — все иконки бренда и знаки в PNG: сплошные (`-crimson`, `-graphite`, `-white`) и готовые водяные знаки с
прозрачностью (`-vodyanoy-svetlyj` для светлого фона, `-vodyanoy-temnyj` для графита, `-vodyanoy-zelenyj` для зелёного).

Шрифт Gilroy встроен в файл. Если он всё равно не отображается, установите шрифты из папки fonts на Drive.

Правка существующего файла: `python3 tools/pptx/patch_user_file.py вход.pptx выход.pptx`.
Полная пересборка с нуля (только если рабочий файл не нужен): `node tools/pptx/extract.js && python3 tools/pptx/build.py новый.pptx`.
Рыба — `tools/pptx/fish.json`, список слайдов и слоты — `tools/pptx/layouts.json`.
