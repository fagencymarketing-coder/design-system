# Каталог макетов v2

Десять утверждённых вариантов, 1080×1080, слоты и лимиты — `docs/layout-catalog.md`.
Рендер: `./render.sh <имя без расширения>` (Chromium). Gilroy берётся из `assets/fonts/` (в git не хранится
из-за лицензии, лежит на Drive в папке `fonts`). Общая плитка: `tile.png`, обзор с подписями: `catalog.png`.
Снятые варианты (V4, V7, V10) лежат в `archive/`. Плашек в системе нет.
