# 1+1 · Система макетов «Тихая дороговизна» (для Claude Design)

**Принцип.** Макет не придумывается с нуля. Берётся один из утверждённых шаблонов из `templates/`, заполняются слоты,
подбирается фото по таблице, проверяется результат. Шаблон × текст × фото × слово-акцент × водяной знак даёт
неограниченное число вариантов, которые выглядят как одна серия.

Полные правила и обоснования: `docs/readme-v2.md` (цвет, типографика, фото, текст). Здесь только порядок работы.

## 1. Порядок работы
1. **Тип контента → шаблон** (таблица ниже). Один шаблон на макет, приёмы разных шаблонов не смешиваются.
2. **Текст.** Только предоставленный пользователем. Разбить на уровни (заголовок, пояснение, дата), расставить
   переносы строк вручную через `<br>`, неразрывные пробелы после односложных предлогов, чисел и в датах.
   Заголовок и мелкий вопрос не заканчиваются точкой. Одно слово-акцент (`<em class="acc">`), не больше.
3. **Фото** по таблице «Фото → шаблон». Новое фото не подбирается, если в библиотеке есть подходящее.
4. **Водяной знак** (только V11 и там, где он есть в шаблоне) по теме из таблицы в `readme-v2.md`, раздел 5.1.
5. **Проверка:** `fit.js` выдаёт `fitStatus=ok`; пять тестов красоты (герой, воздух, один цвет, «убери», лента);
   чек-лист `readme-v2.md`, раздел 14.
6. **Экспорт:** PNG 1080×1080. Основной формат — квадрат.

## 2. Тип контента → шаблон
| Что нужно сказать | Шаблон |
|---|---|
| тема с людьми, заголовок + пояснение, есть кадр с чистой стеной | **V1** |
| вопрос или фраза, которую нужно «услышать» | **V13** (фото) или **V14** (графит) |
| закон, новость, событие, дата | **V2** (графит) или **V3** (зелёный, редко) |
| срочная новость | **U2**, **U3** (если есть срок), **U5**, **U6** |
| команда, найм, обучение | **V6** |
| предложение, «о нас», предмет вместо людей | **V8** |
| результат для клиента, эксперт с PNG-портретом | **V9** |
| мысль, цитата, экспертное мнение с фото | **V10** |
| мягкая тема, мотивация, сезон | **V11** |

Слоты, лимиты и лестницы кегля каждого шаблона — `templates/INDEX.md`. Новые шаблоны не придумываются: если тип контента
не покрыт, сообщить об этом.

## 4. Что можно менять и что нельзя
**Можно:** текст слотов (в пределах лимитов), слово-акцент, фото и кроп, водяной знак по теме, сторону акцента в рамках шаблона.
**Нельзя:** позицию и версию логотипа; цвет акцента (всегда `#D73A61`, на графите `#EA4C74`); заливку малиновым
(фон, плашка, блок, полоса); тени, градиенты, второй декор; лестницу кегля; поля 96 px; цветной текст по зелёному;
затемнение фото ради читаемости; текст на лицах и руках; выдуманный текст, имена, цифры.

## 5. Ритм ленты
Светлый, фото, графит чередуются. Не ставить подряд два графита, два зелёных, два макета с водяным знаком.
Зелёный (V3, U-серии с зелёным) примерно каждый шестой пост.

## 6. Если макет не получается
Текст не помещается при последней ступени → сократить или перейти на шаблон с большей ёмкостью (V9, V10, V11).
Блок лезет на логотип → меньше строк. Нет подходящего фото → V2/V14 вместо фото-шаблона.
