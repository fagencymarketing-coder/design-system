# Мероприятия: айдентика форума «Сказочная бухгалтерия»

Форум имеет собственные элементы (`assets/event/`): девочка с счётами `girl-abacus.png`, орнамент-полоса `ornament.png`, логотип-надпись
`wordmark-skazochnaya-buhgalteriya.png` (сиреневая, узкий шрифт Cramaten), звёзды `stars.png`. Палитра форума: сиреневый градиент
`#7261A3 → #7D7CC6 → #8797E9`, крем `#F3EEDC`, красный `#D6001F` (красный только в орнаменте).

**Два режима анонса**
- **А · в айдентике форума:** сиреневый градиент, крем, надпись-логотип (перекрашена в крем маской), орнамент внизу, девочка справа.
  Логотип 1+1 белый. Один декор: орнамент. «PRO» светло-сиреневым.
- **Б · в стиле 1+1:** `paper`, графит, малиновая «PRO», Gilroy, девочка справа. Без орнамента и надписи-логотипа.

**Общие правила анонса:** порядок сверху вниз: логотип 1+1, форум (метка капсом), название, список тем, дата, место. Темы списком, а не плашками;
«PRO» акцент-маркер. Дата в обычном регистре («5 ноября 2026 года», неразрывные пробелы), капс только в метке. Фото-кадров нет, героиня — девочка.
Плашки и тени не используются. Исходные тексты не меняются, ничего не добавляется. Макеты: `examples/forum-a.png`, `examples/forum-b.png`.
