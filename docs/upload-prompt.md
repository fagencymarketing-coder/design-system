# Промпт для Claude Design: обновить проект из архива

Приложите `claude-design-upload.zip` (или файлы по частям) и отправьте:

---
Это обновление дизайн-системы «1+1». Распакуй архив и обнови этот проект:

1. Замени `readme.md` проекта содержимым `readme.md` из архива целиком. Старые правила из него не сохраняй: они устарели и противоречат новым.
2. Добавь в проект папки `templates/`, `rules/`, `tokens/v2.css` и `assets/` (`icons`, `marks`, `team`, `director`, `experts`, логотипы, `pattern-1.png`, `pattern-2.png`, `badge-round.png`) с теми же именами и путями. Папку `assets/fonts` не трогай.
3. Если есть конфликт с уже существующими файлами, заменяй старые новыми и перечисли, что заменил.
4. Старые `guidelines/` и `ui_kits/` не удаляй, но отметь в `readme.md` строкой «устарело, не использовать», если они противоречат новым правилам.
5. В конце проверь: все ли файлы на месте, открываются ли шаблоны из `templates/` без ошибок. Покажи список изменений.

Дальше при каждой задаче на макет работай по `readme.md`: выбери один шаблон из `templates/`, подставь текст и фото, не придумывай макет с нуля.
